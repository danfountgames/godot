# ISSUES

Reproducible product issues. Fix `CRITICAL` and `MAJOR` before unrelated polish.

Severity: `CRITICAL` (crash, data loss, blocked core loop, unusable release),
`MAJOR` (serious gameplay, comprehension, control or visual failure),
`NORMAL` (material defect with a workaround), `MINOR` (polish).
